# Anchor Web Client

Responsive React + TypeScript installable PWA for phone and laptop browsers. See the root `README.md` for installation, relay configuration, backups and actual feature limitations.

Use a secure HTTPS origin outside localhost. Browser notifications are best-effort while the app can run; this PWA does not provide native background-alarm guarantees. Browser model inference is optional and may need a multi-gigabyte Gemma 4 download. The local capture, encrypted IndexedDB vault and deterministic extractor remain usable without it.
